# Elmullim — Backend Documentation

هذا المجلد هو المرجع التشغيلي للـLaravel Backend الموجود في:

`https://github.com/mazensabry2712/Elmullim-b`

## الملفات

- `BACKEND-OVERVIEW.md` — مكونات الـBackend والوظائف الحالية.
- `API-REFERENCE.md` — خريطة الـAPI الحالية حسب نوع الاستخدام.
- `BACKEND-STRUCTURE.md` — تنظيم الكود والطبقات الرئيسية.
- `OPERATIONS.md` — تشغيل الـBackend وإعداد الخدمات المطلوبة.

## التقنية الحالية

- PHP 8.2+
- Laravel 11
- Laravel Sanctum
- MySQL أو قاعدة البيانات المحددة في البيئة
- Pusher / Laravel Broadcasting
- Musonza Chat
- Vimeo
- Chunked video uploads
- Paymob
- Pest

## نطاق التوثيق

المستندات هنا تشرح **الـBackend الموجود حاليًا وطريقة تشغيله واستخدام واجهاته**. لا يوجد فيها Roadmap أو Future Architecture أو backlog.
