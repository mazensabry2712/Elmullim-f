# Elmullim Backend Documentation

This folder contains the backend audit, architecture, future architecture, and engineering standards for the Elmullim Laravel backend.

- `BACK-PROJECT-ISSUES.md` — high-level issue inventory only.
- `BACK-PROJECT-ISSUES-DETAILS.md` — detailed issue descriptions without solutions.
- `BACK-PROJECT-ARCHITECTURE.md` — target engineering architecture and development system.
- `BACK-PROJECT-FUTURE-ARCHITECTURE.md` — scalable future architecture and migration direction.
