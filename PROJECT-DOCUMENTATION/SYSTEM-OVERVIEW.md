# Elmullim — System Overview

## 1. النظام

Elmullim منصة تعليمية تربط بين ثلاثة أنواع رئيسية من المستخدمين:

- **Student** — الطالب.
- **Teacher** — المعلم.
- **Parent / Family** — ولي الأمر والأسرة.

الـFrontend موجود في `Elmullim-f` ويستهلك خدمات الـLaravel Backend الموجود في `Elmullim-b`.

## 2. الوظائف الحالية

### الطالب

- إنشاء الحساب وتسجيل الدخول.
- التحقق من البريد الإلكتروني.
- استعادة وتغيير كلمة المرور.
- عرض الدورات والدروس.
- التسجيل في الدورات والدروس.
- متابعة المحتوى والمحاضرات.
- إجراء الاختبارات المتاحة.
- تقييم المعلمين.
- متابعة التقييمات.
- الدفع الإلكتروني للدورات والدروس.
- المحادثات.
- الملف الشخصي.

### المعلم

- إنشاء الحساب وتسجيل الدخول.
- التحقق من البريد الإلكتروني.
- إدارة الملف الشخصي.
- إنشاء وتعديل الدورات.
- إدارة محتويات الدورات والمحاضرات.
- إنشاء وتعديل الدروس.
- إدارة محتويات الدروس والمحاضرات.
- رفع فيديوهات المحتوى.
- إنشاء الاختبارات والأسئلة.
- إدارة التقييمات.
- متابعة المحفظة وطلبات السحب.
- المحادثات.

### ولي الأمر

- إنشاء الحساب وتسجيل الدخول.
- التحقق من البريد الإلكتروني.
- إدارة الملف الشخصي.
- متابعة بيانات الطلاب المرتبطين بالحساب.
- متابعة التقييمات.
- تقييم المعلمين.

## 3. المكونات الرئيسية

```text
React Frontend
      |
      | HTTP / JSON
      v
Laravel Backend
      |
      +-- Database
      +-- Authentication / Sanctum Guards
      +-- Payment Integration
      +-- Vimeo Video Integration
      +-- Chat / Broadcasting / Pusher
      +-- File and Video Uploads
```

## 4. المصادقة

الـBackend يستخدم Sanctum مع guards منفصلة حسب نوع المستخدم. الـFrontend يحتوي على route protection حسب حالة تسجيل الدخول والدور.

الحماية الفعلية للبيانات والعمليات موجودة على الـBackend؛ حماية الـFrontend تستخدم لمنع الوصول إلى الصفحات غير المناسبة للمستخدم أثناء التصفح.

## 5. الدفع

توجد عملية بدء دفع للطالب، وواجهة callback للعميل، وWebhook منفصل من Paymob للمعالجة الخلفية. إنشاء أو تحديث الحالة التجارية يجب أن يعتمد على نتيجة الـBackend الموثوقة، وليس على تغيير الصفحة فقط.

## 6. Realtime

المشروع يستخدم Laravel Broadcasting وPusher/Laravel Echo لتحديثات الـRealtime، خصوصًا المحادثات.

## 7. الفيديو

المشروع يحتوي على تكامل Vimeo بالإضافة إلى رفع فيديوهات للمحاضرات، بما في ذلك دعم الرفع على أجزاء في الـBackend.
